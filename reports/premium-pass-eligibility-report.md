## 6. Server-Side Enforcement Rules
1. **Verification Endpoint**: Implemented in `src/lib/pass-eligibility.ts` and verified server-side in `registerStudentServerFn` and `loginStudentServerFn`.
2. **Immutable Pass Category**: Pass category cannot be supplied, selected, or modified by candidates. It is looked up strictly from `src/data/official-participants.ts` (derived from the official Excel sheet).
3. **Dual List Match**: A student must match both the website confirmed list AND the official Excel sheet.
4. **Entertainment Pass Denial**: Any candidate associated with `Entertainment Pass` receives an explicit error:
   > *"Registration Denied: Entertainment Pass holders are not eligible for the Equinox Internship Drive. Only Premium Pass participants can register."*
